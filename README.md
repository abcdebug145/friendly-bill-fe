# Friendly Bill — Frontend

Ứng dụng Angular cho Friendly Bill.

## Chạy local

```bash
npm install
npm start
```

Proxy dev: `proxy.conf.json` → backend `http://localhost:8080`.

## Push lên GitHub

Tạo repo rỗng (ví dụ `friendly-bill-fe`), rồi:

```bash
git remote add origin https://github.com/<USER>/friendly-bill-fe.git
git branch -M main
git push -u origin main
```
